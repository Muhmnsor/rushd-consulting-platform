# خطة تنفيذ صفحات منصة رُشد

هذه الوثيقة تحول مواصفات الصفحات الوظيفية إلى خطة بناء قابلة للاختبار. تبقى
المواصفات الأصلية مرجع النطاق، بينما تحدد هذه الوثيقة ترتيب التنفيذ وحدود كل
واجهة.

## مبادئ التنفيذ

1. Frappe هو محرك البيانات وسير العمل والصلاحيات، وليس واجهة المنتج للمستخدم.
2. الواجهات منفصلة إلى `public` و`portal` و`staff` و`admin`.
3. كل صلاحية تُطبق في الخادم وعلى مستوى السجل، ولا يعتمد المنع على إخفاء عنصر.
4. تستخدم الصفحات قوالب مشتركة: لوحة، قائمة، تفاصيل، نموذج، تقويم، تقرير.
5. تنفذ الرحلات من بدايتها إلى نهايتها قبل الانتقال إلى وظائف ثانوية.
6. كل واجهة عربية RTL ومتجاوبة مع الجوال منذ أول إصدار.

## المرحلة الأولى: رحلة طلب الاستشارة

### الواجهة العامة

- تسجيل الدخول.
- إنشاء الحساب والتحقق في مرحلة لاحقة من الرحلة.

### بوابة المستفيد

- لوحة المستفيد.
- طلب استشارة جديد مع حفظ مسودة.
- قائمة الطلبات والحالة والخطوة التالية.
- الملف الشخصي الأساسي.

### التشغيل

- طابور الطلبات الجديدة.
- مراجعة اكتمال الطلب.
- طلب معلومات إضافية.
- تحويل الطلب إلى الفرز.

### المشرف

- الفرز وتحديد ملاءمة الخدمة.
- الإسناد اليدوي للمستشار.

### معايير اكتمال المرحلة

- لا يستطيع مستفيد إنشاء طلب باسم مستفيد آخر.
- لا يستطيع المستخدم فتح طلب لا يخصه بتغيير الرابط أو معرّف API.
- تظهر حالة الطلب والخطوة التالية بلغة عربية واضحة.
- لا يعرض API بيانات الحقول الداخلية أو المهنية.
- يعمل النموذج على الجوال ويحفظ المسودة.
- توجد رسالة واضحة بأن المنصة ليست مسارًا للطوارئ.
- تمر اختبارات الصلاحيات والرحلة الكاملة.

## المرحلة الثانية: الموافقات وولي الأمر

- حساب ولي الأمر المستقل.
- الربط والتفويض محدد النطاق والمدة.
- الموافقة ذات الإصدار والتوقيع أو OTP.
- فصل إجابات ولي الأمر عن إجابات المستفيد.
- عدم إظهار الملاحظات المهنية أو روابط الجلسات الخاصة دون سياسة صريحة.

## المرحلة الثالثة: المواعيد والجلسات

- التوفر والحجب ومنع التعارض داخل Transaction.
- الحجز والإلغاء وإعادة الجدولة.
- توثيق الجلسة بثلاثة مخرجات منفصلة:
  - ملاحظة مهنية داخلية.
  - ملخص للمستفيد.
  - ملخص لولي الأمر عند السماح.
- اعتماد السجل ومنع تعديله دون Revision أو Amendment.

## المرحلة الرابعة: الخطة والمقاييس والمتابعة

- الأهداف والمؤشرات والمهام.
- قوالب المقاييس وإصداراتها.
- التقييم القبلي والبعدي.
- النتائج المبسطة حسب سياسة العرض.

## المرحلة الخامسة: الإشراف والجودة والتشغيل

- مراجعة الجلسات والخطط.
- طلبات الإشراف والتصعيد.
- الشكاوى السرية ومنع تضارب المصالح.
- التقارير التشغيلية والجودة الأساسية.

## المرحلة السادسة: الإدارة والمحتوى والتكامل

- المستخدمون والأدوار والنطاقات.
- الخدمات وقوالب النماذج والموافقات.
- الإعلانات والمحتوى حسب الجمهور.
- التكاملات بعد اعتماد البيانات التي يسمح لها بمغادرة رُشد.

## مصفوفة الأسطح

| السطح | المستخدمون | ما يظهر |
| --- | --- | --- |
| `rushd.sa` | الزائر | التعريف والخدمات والسياسات والدخول |
| `portal.rushd.sa` | المستفيد وولي الأمر | الطلب والموافقة والموعد والملخصات المسموحة |
| `staff.rushd.sa` | المستشار والمشرف والتشغيل | الحالات المسندة والفرز والجلسات والإشراف |
| `admin.rushd.sa` | الإدارة ومسؤول النظام | المستخدمون والإعدادات والتقارير والتكاملات |
| `api.rushd.sa` | واجهات رُشد فقط | عقود API محددة بأقل بيانات لازمة |

## الحالة الحالية

- اكتمل قالب بوابة المستفيد العربي والمتجاوب.
- اكتملت لوحة المستفيد.
- اكتمل إنشاء طلب استشارة وحفظه كمسودة وإرساله.
- اكتملت قائمة الطلبات والحالة والخطوة التالية.
- اكتملت صفحة بيانات المستفيد والتحديث الذاتي للحقول الآمنة.
- اكتملت واجهة مستقلة للاستقبال والتشغيل.
- اكتمل طابور مراجعة اكتمال الطلب وطلب الاستكمال والتحويل للفرز.
- اكتملت واجهة المشرف وطابور الفرز وقرارات الملاءمة.
- فُصلت الملاحظات الداخلية عن التوضيح العام الذي يظهر للمستفيد.
- اكتملت لوحة ولي الأمر والمستفيدون المرتبطون وصلاحيات الوصول.
- اكتمل أساس الموافقات: القالب، النسخة غير القابلة للتعديل بعد النشر، وسجل الموافقة.
- اكتملت صفحة موافقات ولي الأمر وتسجيل الموافقة من الويب.
- اكتمل تحويل الطلب المؤهل إلى حالة وإسناده يدويًا إلى مستشار متوافق مع الخدمة.
- يمنع الإسناد المكرر، ويتحقق من نشاط المستشار وموافقة ولي الأمر عند اشتراطها.
- اكتملت لوحة المستشار الأساسية وقائمة الحالات وتفاصيل الحالة ضمن نطاق المستشار.
- اكتمل الحجز الأساسي مع التحقق من التوفر ومنع التعارض.
- اكتملت صفحة جدول المستشار للمواعيد القادمة والسابقة وتسجيل الحضور أو عدمه.
- اكتمل سجل الجلسات وطابور السجلات غير الموثقة أو المعادة للاستكمال.
- اكتمل نموذج توثيق الجلسة مع فصل الملاحظة المهنية عن ملخص المستفيد وملخص ولي الأمر.
- يمنع المستفيد وولي الأمر والتشغيل من قراءة سجل الجلسة المهني.
- يدعم السجل المسودة والإرسال للمراجعة والاعتماد والإعادة، ويمنع تعديل السجل المعتمد.
- اكتمل طابور مراجعة الجلسات للمشرف مع عرض التوثيق المهني والملخصات بصورة منفصلة.
- يتيح للمشرف اعتماد الجلسة أو إعادتها بسبب إلزامي، ويمكن للمستشار استكمالها وإرسالها مجددًا.
- لا تُحتسب الجلسة في تقدم الحالة إلا بعد اعتماد المشرف، ويمنع اعتمادها أو احتسابها مرة أخرى.
- اكتمل محرر الخطة الاستشارية للمستشار مع المسودة والأهداف والمؤشرات وحدود الظهور للمستفيد.
- اكتمل طابور مراجعة الخطط للمشرف مع الاعتماد أو الإعادة بسبب إلزامي.
- لا تظهر الخطة للمستفيد قبل اعتمادها، ولا تظهر له الأهداف المهنية الموسومة بأنها داخلية.
- اكتملت مهام المستفيد المرتبطة بالخطة النشطة، مع تحديث التقدم والملاحظة من حساب المستفيد فقط.
- أضيفت الخطط والمهام إلى لوحة الإدارة، مع تعريب الحقول والحالات وتطبيق صلاحيات السجل.
- اكتملت مكتبة المقاييس بقالب مستقل وإصدارات ثابتة لا يمكن تعديلها بعد النشر.
- اكتمل إسناد المقياس القبلي أو الدوري أو البعدي من المستشار إلى حالة مسندة إليه.
- يستطيع المستفيد حفظ الإجابات واستكمالها ثم إرسالها، دون صلاحية لقراءة سجل النتائج المهني مباشرة.
- اكتملت مراجعة المستشار مع فصل التفسير المهني الداخلي عن الملخص المسموح للمستفيد.
- لا تعرض النتيجة للمستفيد تلقائيًا؛ يتطلب عرضها مراجعة مهنية وسياسة قالب تسمح بذلك.
- اكتملت المقارنة الزمنية للمستشار والمتابعة الإشرافية، مع تنبيه واضح بأن المؤشر ليس تشخيصًا أو قرارًا آليًا.
- أضيفت قوالب المقاييس وإصداراتها ونتائجها إلى لوحة الإدارة مع تعريب الحقول والحالات.
- اكتملت الإحالات الداخلية والخارجية مع نطاق البيانات والموافقة والاعتماد الإشرافي والمتابعة حتى الإغلاق.
- اكتملت طلبات الإشراف المرتبطة بالحالة، مع عزلها حسب المشرف وتوثيق الرد والإجراء وموعد المتابعة.
- اكتملت التنبيهات والتصعيدات المهنية بدرجات الخطورة، والإجراء الفوري، وسجل استجابة المشرف والحل.
- لا تُظهر السجلات المهنية الثلاثة للمستفيد أو ولي الأمر، ولا يستطيع مستشار أو مشرف الوصول إلى سجل خارج نطاقه.
- أضيفت الإحالات وطلبات الإشراف والتصعيدات إلى لوحة الإدارة، ولوحتي المستشار والمشرف، مع تعريب كامل للحالات والحقول.
- اكتملت الحالات تحت الإشراف مع مراجعة مجمعة للجلسات والخطط والمقاييس والإحالات وطلبات الإشراف والتنبيهات.
- اكتملت صفحة أداء المستشارين وتقارير الإشراف والجودة ضمن نطاق المشرف، دون استخدام المؤشرات كقرار مهني آلي.
- اكتملت صفحات توفر المستشار وطاقته وملفه المهني وتطويره وتقاريره، مع تحديث الحقول الآمنة من بوابة المستشار.
- اكتملت صفحات التشغيل للمواعيد والحضور وخدمة المستفيد وقائمة الانتظار ودليل جهات الإحالة.
- اكتمل مركز الدعم التشغيلي بطلب مستقل ورد عام وملاحظة داخلية، مع عزل كل مستخدم عن طلبات الآخرين.
- اكتملت الشكاوى والاقتراحات وطلبات تغيير المستشار مع السرية والتحقيق والإجراء والرد والإغلاق الموثق.
- اكتملت ملفات الحالة بسياسة ظهور مستقلة للمستفيد وولي الأمر، ولا تعرض صفحة «ملفاتي» إلا الملفات المصرح بها.
- اكتملت الإعلانات الداخلية ومكتبة المحتوى الموجه حسب الدور والخدمة والعمر، مع صفحات إدارة عربية.
- اكتملت مسارات الإدارة من `/admin` حتى المستخدمين والأدوار والخدمات والمقاييس والموافقات والمحتوى والشكاوى والتقارير والتدقيق والخصوصية والتكاملات والأمان.
- اكتملت الصفحات ذات الأولوية في خطة التنفيذ، وتبقى التكاملات الخارجية المتقدمة وSSO وتطبيق الجوال ضمن المراحل اللاحقة خارج صفحات الإصدار الحالي.
